# Host Agent V1 1.2.8 unsigned preview

**Release description draft — not published.** This is an unsigned preview for
authorized testing in the approved Windows DEV VM. No SignPath application,
sponsorship, or signature is claimed.

Host Agent V1 is a Windows-first local monitoring and incident-assistance
application with a Czech desktop dashboard, local history and evidence-based
diagnoses and recommendations. It collects bounded system, CPU/memory, disk,
process/service, network and Event Log metadata. The package includes the
documented local administrative helper with typed allowlisted actions and
operation-specific approval.

## Safe defaults and limitations

- Fresh installation defaults to **Shadow / read-only**. This preview was
  installed and inspected in the approved DEV VM; the owner-supplied result
  confirmed configuration preservation, matching installed critical hashes,
  and both services Running during the read-only preview probe.
- The initial installed acceptance result remained **incomplete**. The
  dashboard showed partial CPU/process telemetry because access to some
  process CPU values and executable paths was denied. These metrics remain
  visibly partial; this preview does not claim that limitation is fixed.
- Optional SMART health may be unavailable. Pushover, outbound heartbeat and
  active connectivity probes are off unless explicitly configured by the
  operator. See the [privacy and network disclosure](../operations/privacy.md)
  and [announced installation changes](../operations/submission-preview.md).
- Owner-supplied offline-copy SQLite checks returned `quick_check=ok` for
  `host-agent.db` and `notifications.db`. The helper-journal database was
  absent and was not checked. A later owner-run recovery returned both
  services to Running; this is not a claim that every database is present or
  that application-level acceptance is complete.
- This preview has not been tested or approved for production deployment.
  Preserve normal Windows security protections. If installation is blocked,
  stop and retain the error; do not weaken system policy.
