1. Duplicate aliases for a real target could partition guard counts. Red run 23; fixed by rejecting duplicate local service names/process paths; green run 24.
2. Guard refusal left AUTO_ALLOWED as the last audit decision. Red run 23; fixed by appending the final DENIED code; green run 24.

4. Audit lacked typed parameters and timeout. Red run 26; persisted as explicit fields; green run 27.
5. A synchronously blocked executor bypassed the wait timeout. Red run 28; invocation is isolated from the caller's bounded wait, with durable uncertainty; green run 29.

No unresolved actionable finding remains in the reviewed range. Specific guard denial codes persist the need for human intervention. Automatic monitoring incident Escalated transitions and notifications remain service orchestration/Task 4 work, not privileged helper execution.

## Limits and deployment assumptions

- Administrators/SYSTEM and the installed helper binary/configuration are trusted. SQLite triggers are append-only application guards, not cryptographic tamper resistance against an administrator who can replace the database.
- Current protocol supports four capabilities only: StartService, StopService, RestartService, TerminateProcess. Flush DNS, DHCP renewal and Windows restart are potential future capabilities, absent from the discriminator set and impossible to enable through this configuration. Default registrations and approver list are empty.
- Configuration is a protected local snapshot loaded on startup; changes require restart. A protected `disable-remediation` marker is checked before each request/invocation. There is no remotely editable policy endpoint.
- Native APIs can continue/complete after the caller stops waiting. Uncertain attempts therefore block the target and require trusted human investigation; no automatic claim-clearing route was added.
- Installed Windows Service identities, distinct-account production ACL behavior, SCM startup/recovery, real service/process mutations, signed deployment, live approval UI and long-running operation were not exercised. Tests create no accounts, install no services and execute no destructive actions.
- Task 4 was not started. Source transfer/deployment to the protected host did not occur.
